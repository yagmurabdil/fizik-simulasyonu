# Uzayda Fizik Simülasyonu (C)

Bu proje, kullanıcıdan alınan verilerle Güneş Sistemi’ndeki 8 gezegen için çeşitli fizik deneylerini hesaplayan, menü tabanlı bir C programıdır.  
Amaç, temel fizik formüllerinin ve C programlama dilinin kontrol yapılarının uygulamalı olarak kullanılmasıdır.

## Deneyler

Program aşağıdaki deneyleri içerir:

1. Serbest düşme  
2. Yukarı atış  
3. Ağırlık  
4. Kütleçekimsel potansiyel enerji  
5. Hidrostatik basınç  
6. Arşimet kaldırma kuvveti  
7. Basit sarkaç periyodu  
8. Sabit ip gerilmesi  
9. Asansör deneyi (etkin ağırlık)

## Programın Özellikleri

- Menü tabanlı kullanıcı etkileşimi  
- Hatalı girişler için kontrol mekanizması  
- Her deneyin farklı gezegenlerin yerçekimi ivmesine göre hesaplanması  
- Tek kaynak dosya (`main.c`) kullanımı

## Dosya Yapısı

- `main.c` : Programın tüm kaynak kodu
